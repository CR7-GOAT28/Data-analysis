# Customer Churn: Data Quality and Exploratory Analysis

## Files
- `customer_churn_raw_transcribed.csv` — raw records transcribed from the supplied screenshot.
- `cleaned_customer_churn.csv` — cleaned, analysis-ready dataset.
- `customer_churn_analysis.ipynb` — reproducible Python notebook.
- `data_quality_report.pdf` — quality audit, findings, charts and recommendation.

## Run
1. Install Python 3 and Jupyter.
2. Install dependencies: `pip install pandas numpy matplotlib`.
3. Open the notebook in Jupyter.
4. Keep the raw CSV in the same folder and run all cells.

## Important data provenance
The supplied image showed 15 synthetic customer records. The raw CSV in this package was manually transcribed from that screenshot, not downloaded directly from the original Edvyro CSV resource. Compare it with the original download before submitting. If the original contains more records or any differences, replace the raw CSV and rerun the notebook.

## Key limitation
All findings are descriptive and based on a 15-record sample. They must not be interpreted as causal or predictive.
